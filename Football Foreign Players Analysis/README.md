# Football Foreign Players Analysis

A comprehensive exploration of foreign player nationalities in Europe’s “Big 5” football leagues. This project traces the evolution of international talent across the Premier League, Serie A, La Liga, Ligue 1, and the Bundesliga from the late 1980s through the 2024–25 season, and provides an aggregated “Big 5” overview of country‐level trends.
